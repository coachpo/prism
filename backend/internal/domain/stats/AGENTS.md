# Statistics Read Models

`scope.go` owns the public scope/metric/group/filter catalog and caliber/sample/coverage contract. Keep HTTP parsing and response writing in [management/stats](../../httpapi/management/stats/AGENTS.md). Product semantics are documented in [Architecture](../../../../docs/architecture.md).

- Use retained `request_logs`, `usage_request_events`, and endpoint-label snapshots. Do not infer missing historical `upstream_model_id`/`final_upstream_model_id` from current configuration or logical model identity; project non-positive retained attribution IDs as null without rewriting history.
- Keep `ingress`, `final_execution`, and `route_attempt` grains distinct. Canonical money requires `pricing_status=priced` and trusted pricing evidence; ingress/final groupings are non-additive projections of one served-final fact and attempts make no cost claim. Trusted zero has a sample and a non-null zero; no trusted sample is null.
- Preserve row-scoped status and duration through `request_log_scope.go`; never coalesce upstream/gateway/legacy statuses. Preserve the separate stream completion and response-header duration evidence. Final-execution latency joins the finalized attempt by profile, ingress ID, and attempt number, with missing samples when request history has expired.
- `request_logs.go` and `request_logs_chain_cohort.go` own retained filters: same-key lists are OR, different keys are AND, `__null__` means unattributed, and caller `client_rule_id` remains separate from targets. Keep ingress, attempt-target, and finalized-target model filters distinct; reject retired ambiguous model keys and the `priced` alias at the HTTP boundary.
- `retention_source.go` is the shared cutoff/floor/epoch/purge owner for Observe, Requests, Audit, Events, and Settings. Never reconstruct floors from policy days or `MIN(created_at)`; reads fail closed while purge is running or recovery is required.
- `RefreshActualCoverageProjection` and `RecordActualCoverageAppend` in `retention_source.go` own bounded refresh and the same-transaction append handoff. Preserve source/coverage revisions, hash, generation/fence, materialization cut, freshness, and gaps; consumers must not synthesize intervals or zero counts.
- `observe_query_context.go` owns opaque query-context signing. Fragments use resolved bounds instead of re-parsing presets; retention final publication revokes stale tokens with the dataset snapshot error.
- `request_logs_chain*.go` owns whole-ingress outer pages, bounded retained-row inner pages, and finalized summaries from usage events. Bind cursors to the complete normalized cohort/window, profile, order, page size, and retention generation; items, totals, and CSV must select the same complete chains.
- `request_logs_export.go` requires one read-only repeatable-read snapshot for bounds, count, and spool. Finish typed rejection and spool verification before file bytes; the 31-day limit is export-specific and exact-ingress reads use the retained-history boundary.
- `cost_segments.go` and `classifier.go` must classify epochs and null/non-canonical currency identically in Go and SQL. Retained cost-segment/card-role/selection-state filters reuse canonical predicates; cost-segment selection alone does not change the ingress source.
- `observe_usage_summary_segments.go` derives selected-card-role cost breakdown in the same aggregate statement from trusted usage evidence. `observe_attempt_outcome.go` owns upstream-attempt outcome classification; attempt errors/series preserve replay filters and calculate Top-N/Other from the full denominator.
- Keep backend-derived pricing, usage, output-rate, and latency values authoritative. Preserve measured-sample counts and null gaps; frontend presentation must not recompute aggregate math or replace missing evidence with zero.
- Dashboard aggregate snapshots and recent activity remain separate read models. Activity uses finalized ingress events, not a reconstruction from attempt rows.
