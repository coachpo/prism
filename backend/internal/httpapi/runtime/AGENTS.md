# Runtime HTTP Guidance

`operations.go` is the executable method/path, hook, streaming, and model-binding registry. Its route-witness projection is read-only input to management diagnostics. Keep provider differences in operation request/response/stream hooks and gateway adapters, sharing the executor in `ingress.go` and `request_execution_loop.go`.

- Reject unregistered/wrong-method operations before body reads, runtime admission, transport, and durable side effects. `GET /v1/models` remains a local OpenAI list of enabled direct entries.
- Resolve client model ids exactly through the direct-entry index while recursive Model Targets use the all-enabled graph. Runtime uses the published snapshot, never management profile headers or session state.
- Apply `single|fill-first|round-robin` once to the mixed Model Target/Terminal Target sequence in authored `(position, id)` order. A recursive child remains one contiguous block; changes to the authored enabled target set/order must change the round-robin set hash.
- OpenAI text attempts require strict equality between the model mode and target capability plus native support for the ingress operation (`operation_capability_gate.go`). Never translate Chat/Responses. Image gates independently require both sides to serve the requested image operation; text capability cannot satisfy an image gate.
- Freeze one planning clock at ingress. Gemini probe/final planning, routing schedules, and pricing-card selection reuse it even when body reading separates phases; execution admission and Ban rechecks use live time.
- Evaluate routing schedules through `DecideAt` after the Ban filter in `planning_access_resolution.go`. Unconfigured schedules remain unrestricted. Emit schedule-only planning codes only when deduplicated exclusion evidence proves that attribution; mixed causes retain ordinary failure behavior.
- Owner-backed runtime targets require nonblank frozen `upstream_model_id`; invalid replacement snapshots fail and retain the last-good generation, while orphan connections stay excluded. Provider body/path rewriting uses that id; routing, pricing, and resolved-model attribution retain logical model identity.
- Apply custom request parameters as a per-attempt shallow overlay after native rewrite, then extract generation evidence from that final body. Configured candidates force replayable bodies; Gemini's nil-body probe must not overlay or reject prematurely. Preserve object, encoding, size, and invalid-snapshot rejection boundaries.
- Keep token-count and image operations on their own parsing/usage hooks. Image audit redaction runs before persistence. Failure evidence uses bounded `../../domain/safediag/` projections, not raw upstream diagnostics.
- `stream_output_evidence.go` owns visible-delivery measurement. Persist one verdict on the final attempt and usage event; unknown historical evidence, bursts, and insufficient samples never become a fabricated measured rate.
- Preserve typed pricing-card selection and frozen schedule evidence. NULL price components remain missing, and schedule-unresolved pricing is ordinary missing evidence, not a poison event.
- Keep the telemetry outbox's metadata/artifact identity, idempotent convergence, durable handoff, and joint acknowledgment intact (`telemetry_outbox.go`, `response_write_handoff.go`). Use `feedback_pipeline.go` and `runtime_side_effects.go` for their worker handoffs, and `log_partitions.go` with platform retention for partition ownership.

Run the affected runtime package tests for hook/planning/telemetry seams. The [runtime regression suite](../../../tests/runtime/AGENTS.md) owns operation matrices, native compatibility, rejected-route isolation, and stream/body boundaries; shared backend validation commands remain in [CONTRIBUTING.md](../../../../CONTRIBUTING.md).
