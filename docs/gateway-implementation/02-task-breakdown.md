# Gateway Implementation Task Breakdown

This backlog is implementation guidance for the clean gateway-core replacement. The current documentation task does not modify application source files; the source paths below are likely affected when implementation begins.

Each implementation task is TDD-first: add or update failing tests, implement the smallest passing change, run the real gateway surface through mock upstreams, and delete obsolete code only after equivalent tests pass.

## Recommended Order of Implementation PRs or Commits

1. PR 1: Add gateway core skeleton, operation registry tests, and no-op bridge (`T01`, `T02`).
2. PR 2: Add provider adapter interface and route configuration model (`T03`, `T04`).
3. PR 3: Implement admission reservation, QPS overflow, and routing redirects (`T05`, `T06`, `T07`).
4. PR 4: Implement context-window overflow fallback on the new route planner (`T08`).
5. PR 5: Migrate OpenAI LLM endpoints and conversion (`T09`).
6. PR 6: Migrate OpenAI image generation/editing (`T10`).
7. PR 7: Migrate Anthropic and Gemini adapters (`T11`, `T12`).
8. PR 8: Enforce streaming pump commit boundary (`T13`).
9. PR 9: Move logging, audit, usage, and pricing to typed accounting events (`T14`).
10. PR 10: Add typed hook phases (`T15`).
11. PR 11: Delete obsolete orchestration, old planner rollout config, and public hook-map seams while keeping active tested hedging (`T16`).
